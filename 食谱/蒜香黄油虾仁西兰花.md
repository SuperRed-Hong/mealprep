# 蒜香黄油虾仁西兰花

英文视频，语速慢步骤直白。这道热量最低、蛋白密度最高，跟其他几道形成对比，避免全是鸡胸。

## 步骤
1. 虾仁解冻，厨房纸拍干水分
2. 锅中融化黄油，蒜末爆香
3. 虾仁下锅煎至变红，两面各约1-2分钟
4. 加入冷冻西兰花翻炒至熟
5. 撒盐和黑胡椒调味，配米饭一起吃
