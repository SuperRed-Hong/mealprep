# 照烧鸡胸配洋葱西兰花

视频简介里给了完整文字步骤，已核对跟标题一致：鸡胸肉+洋葱+西兰花+生抽+老抽+蜂蜜+蚝油。

## 步骤
1. 用刀背把鸡胸肉两面锤松，用姜蓉膏、料酒、盐、黑胡椒腌制30分钟
2. 调照烧汁：酱油、蜂蜜、料酒、蚝油、清水搅拌均匀（没有老抽就用酱油顶替，颜色浅一点但不影响味道）
3. 锅中烧热油，洋葱丝煎香煎软、边缘微焦捞出备用
4. 鸡胸下锅煎至两面金黄
5. 倒入照烧汁小火焖煮，洋葱丝和冷冻西兰花一起放入煮2-3分钟
6. 汁烧到浓稠关火，鸡胸切块摆盘
