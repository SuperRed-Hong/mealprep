# 蒜香黑椒烤箱鸡胸 + 烤土豆 + 烤西兰花

这道是本人已经实测过的方法（见 [[厨房清单]]），视频只是交叉验证用的，步骤和数字完全对得上。

## 关键数字（唯一要记的）
- 烤箱预热 **218°C / 425°F**
- 温度针插最厚处，**中心到74°C / 165°F 立刻出炉**
- 出炉后**静置5分钟再切**，别跳过这步

## 步骤
1. 厨房纸拍干鸡胸表面，厚的一头压平到约2cm厚
2. 两面抹牛油果油，撒海盐、黑胡椒、蒜粉、迷迭香粉
3. 土豆切块，烤盘铺锡纸，土豆先烤15分钟
4. 放入鸡胸和冷冻西兰花同烤，摆开别挤（挤了出水变成蒸）
5. 烤16-20分钟，16分钟起用温度针戳最厚处
6. 中心到74°C立刻出炉，静置5分钟再切

## 升级版
提前撒盐冷藏30分钟以上（干腌）再烤，明显更嫩。
